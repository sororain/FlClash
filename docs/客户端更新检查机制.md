# 客户端更新检查机制

> 当前实现基于 **V2Board 面板**（iqoo 模块）。旧的 GitHub releases 兜底检查已在迁移时移除，**当前只有面板这一条更新来源，无双轨兜底**。

## 1. API 接口

### 获取版本信息

```
GET {baseUrl}/{apiPath}/client/app/getVersion?token={subscribe_token}
```

- **认证方式**: 需要登录后的 subscribe token（`requestService.token`），URL 由 `UpdateService.checkForUpdate()` 动态拼接
- **无 token 时直接返回 null，不检查更新**（未登录自动模式静默跳过）

### 返回格式

```json
{
  "data": {
    "android_version": "2.0.7",
    "android_download_url": "https://...",
    "macos_version": "2.0.7",
    "macos_download_url": "https://...",
    "windows_version": "2.0.7",
    "windows_download_url": "https://..."
  }
}
```

平台字段映射：

| 平台 | 版本字段 | 下载链接字段 |
|------|---------|-------------|
| Android | `android_version` | `android_download_url` |
| macOS | `macos_version` | `macos_download_url` |
| Windows / 其他 | `windows_version` | `windows_download_url` |

## 3. 完整流程

### 3.1 `UpdateService.checkForUpdate()` — 请求版本信息

```dart
// lib/iqoo/services/update_service.dart
static Future<Map<String, dynamic>?> checkForUpdate() async {
  // 1. 获取 baseUrl 和 token，缺一不可（未登录不检查）
  final baseUrl = requestService.baseUrl;
  final token = requestService.token;
  if (baseUrl == null || token == null) return null;

  // 2. 拼接 URL: {baseUrl}/{apiPath}/client/app/getVersion?token={token}
  final sep = baseUrl.endsWith('/') ? '' : '/';
  final apiPath = requestService.apiPath;
  final cleanPath = apiPath.startsWith('/') ? apiPath.substring(1) : apiPath;
  final url = '$baseUrl$sep$cleanPath/client/app/getVersion?token=$token';

  // 3. 发起 GET 请求（独立 Dio 实例，UA = browserUa）
  final dio = Dio(BaseOptions(headers: {'User-Agent': browserUa}));
  final response = await dio.get(url, options: Options(responseType: ResponseType.json));
  if (response.statusCode != 200) return null;

  // 4. 按平台取对应版本号 / 下载链接字段
  //    Android → android_version / android_download_url
  //    macOS   → macos_version   / macos_download_url
  //    其他    → windows_version / windows_download_url

  // 5. 与本地版本号对比（compareVersions，去掉远程版本号的 v 前缀）
  final hasUpdate = utils.compareVersions(remoteVersion.replaceAll('v', ''), version) > 0;
  if (!hasUpdate) return null;

  // 6. 有新版本则返回数据
  return {
    'tag_name': 'v$remoteVersion',
    'body': '',           // 更新日志（面板暂未提供，固定空）
    'download_url': v2Data[downloadKey] ?? '',
  };
}
```

**返回值**：
- `null` → 未登录、请求失败、无新版本
- `{tag_name, body, download_url}` → 有新版本

### 3.2 `UpdateHelper.handleResult()` — 处理更新结果

```dart
// lib/iqoo/help/update_helper.dart
static Future<void> handleResult(
  ProviderContainer container, {
  Map<String, dynamic>? data,
  bool isUser = false,   // true=用户手动触发, false=启动时自动检查
}) async {
  if (data != null) {
    // 有新版本 → 弹窗
    final tagName = data['tag_name'];
    final body = data['body'];
    final submits = utils.parseReleaseBody(body);  // 解析更新日志

    final res = await globalState.showMessage(
      title: loc.discoverNewVersion,
      message: TextSpan(text: '$tagName \n', ...),
      confirmText: loc.goDownload,
      cancelText: isUser ? null : loc.noLongerRemind,
    );

    if (res == true) {
      // 用户点了"去下载"
      final downloadUrl = data['download_url'] as String?;
      if (downloadUrl != null && downloadUrl.isNotEmpty) {
        launchUrl(Uri.parse(downloadUrl), mode: LaunchMode.externalApplication);
      } else {
        showMessage('下载链接暂未配置');   // 仅文案提示，非第二更新来源
      }
    } else if (!isUser && res == false) {
      // 自动检查模式 + 点"不再提醒" → 关闭自动更新
      container.read(appSettingProvider.notifier)
          .update((state) => state.copyWith(autoCheckUpdate: false));
    }
  } else if (isUser) {
    // 手动点击检查 + 无更新
    showMessage('检查更新失败');
  }
}
```

## 4. 状态流转

```
[启动(已登录) / 用户点击]
       │
       ▼
UpdateService.checkForUpdate()
       │
       ├── baseUrl/token 为空 → return null（未登录，自动模式静默跳过）
       │
       ▼
  请求面板 API /client/app/getVersion?token=...
       │
       ├── 请求失败 → return null
       │
       ▼
  版本对比（compareVersions）
       │
       ├── 无新版本 → return null
       │           → (用户手动时) 弹窗"检查更新失败"
       │
       ▼
  UpdateHelper.handleResult(data)
       │
       ├── 弹窗显示版本号 + 更新内容
       │
       ├── 用户点"去下载"
       │   ├── 有 download_url → 打开下载链接
       │   └── 无 download_url → 弹窗"下载链接暂未配置"
       │
       └── 自动检查 + 用户点"不再提醒"
           → 关闭自动更新 (appSetting.autoCheckUpdate = false)
```

## 5. 触发条件 / 注意点

- **仅登录后检查**：自动检查在 `checkAuth()` 内，未登录（无 token）直接跳过，不请求。
- **启动时机靠后**：要等 OSS 服务器地址竞速 → 拉站点/用户配置 → 刷新订阅 token → 同步订阅全部完成，才执行自动更新检查（保证使用最新 baseUrl）。
- **「不再提醒」即关闭**：自动模式下点「不再提醒」会把 `autoCheckUpdate` 置 `false`，之后启动不再检查；可在设置页「自动检查更新」重新开启。
- **无 GitHub 兜底**：0.8.93 的 `common/request.dart checkForUpdate()`（GitHub releases API）已删除，当前**不依赖 GitHub**，唯一来源是 V2Board 面板。
